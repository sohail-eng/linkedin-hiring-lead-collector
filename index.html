Purpose

View and analyze hiring leads collected from LinkedIn using the Hiring Lead Collector Chrome extension. Upload your exported data to filter, search, and explore job opportunities.

📥

How to Use

  1. Install the Chrome extension (download below)
  2. Go to LinkedIn feed or search results (#hiring, #jobs)
  3. Open extension → Set optional location/keyword filters; use the top-right gear to optionally add an Ollama Cloud API key for uncertain hiring posts
  4. Click Start → Scroll through posts
  5. Click Stop Collection, then separately click Export All Saved Leads
  6. Upload the .csv or .json file here
✨

Features

  • Smart Filters: By email, apply link, company
  • Live Search: Across all fields instantly
  • Sort & Paginate: By date, author (25/page)
  • Detail Panel: Click row for full lead info
  • Description Modal: Click description to expand
  • Hiring screening: A local guard labels candidates KEEP, DENY, or CONFUSE; all labels are saved/exported for testing, and Ollama Cloud can review uncertain cases
  • Responsive: Works on mobile & desktop
📊

Data Fields

  • Post date & original label
  • Author name & company
  • Full post description
  • Extracted emails
  • Application links (lnkd.in, job URLs)
  • Post URL (open on LinkedIn)
  • Relevance & status tracking

Auto-Apply Workflow

Score each exported job post against your CV with Ollama Cloud. If the score is greater than 70, generate a short human email and send it with your CV PDF. Progress is saved so duplicates are never processed twice.

Download Auto-Apply (ZIP)

You only need this ZIP from the site — no need to clone the GitHub repo.

1. Download and extract

  1. Click Download Auto-Apply (ZIP) above (or use the footer link).
  2. Extract the ZIP anywhere on your computer (Downloads is fine).
  3. You should get a folder named apply-workflow containing:
    • apply_jobs.py
    • requirements.txt
    • .env.example
    • cv-compress-prompt.md
    • cv.md.example
    • README.md
  4. Open a terminal inside that apply-workflow folder for the steps below.

macOS / Linux: right-click ZIP → Open / Extract, or unzip apply-workflow.zip. Windows: right-click → Extract All.

What the script does

  1. Load hiring-leads.csv + cv.md
  2. Skip leads already listed in apply-results.json
  3. Send post + CV to Ollama → get match score
  4. Always save the score for that post
  5. If score > 70 → generate email → send email + cv.pdf → save
  6. If score ≤ 70 → save with score only (no email)
  7. Move to the next post
  8. If any Ollama call fails → print the error and stop

2. Required files you add (exact names)

After extracting, put these inside the same apply-workflow folder:

File Purpose
hiring-leads.csv Leads exported from the extension (must use this exact filename)
cv.pdf Full CV PDF attached to application emails
cv.md Compressed CV text used by Ollama (keeps tokens low)
.env Ollama API key + SMTP credentials (copy from .env.example)
apply-results.json Created automatically — processing log / dedupe store

3. Export and name the leads file

  1. In the Chrome extension, click Export All Saved Leads (CSV).
  2. Move that file into your extracted apply-workflow folder.
  3. Rename it exactly to hiring-leads.csv (overwrite when you refresh leads).

4. Create compressed cv.md (token-saving)

Ollama compares cv.md + each job post. Use a short markdown CV, not the full PDF text. Copy the prompt below into ChatGPT / Claude / any AI, attach your real CV, and save the reply as cv.md inside your extracted apply-workflow folder. The same prompt is also in cv-compress-prompt.md inside the ZIP.

CV compress prompt 
You are compressing a CV for a low-token job-match pipeline.

Rewrite the CV into a short markdown file. Rules:

1. Output ONLY the compressed CV markdown. No intro, no tips, no extra commentary.
2. Keep facts accurate. Do not invent employers, titles, dates, skills, or metrics.
3. Target 250–450 words max.
4. Use this exact structure and headings:

# Name
- Role target: <1 short line>
- Location / work mode: <city or Remote>
- Years experience: <number or range>
- Email: <email>
- Phone: <optional>
- Links: <portfolio / LinkedIn / GitHub, optional>

## Summary
<2 short sentences max>

## Core skills
- Languages:
- Frameworks:
- Tools / cloud / DB:
- Soft / domain:

## Experience
### <Title> — <Company> (<dates>)
- <1–2 bullets: impact + stack only>

### <Title> — <Company> (<dates>)
- <1–2 bullets>

## Education
- <degree / school / year>

## Highlights
- <up to 3 short proof points that help match job posts>

5. Prefer nouns and concrete stack names over fluff (“passionate”, “team player”, “results-driven”).
6. Drop hobbies, references, photo notes, and long project essays unless they prove a skill.
7. If something is unknown, omit the line instead of guessing.

Also place your real PDF as cv.pdf in the same folder (this is what gets emailed).

5. Create .env credentials

  1. Open a terminal in the extracted apply-workflow folder.
  2. Copy the example env file:
    macOS / Linux: cp .env.example .env
    Windows (Command Prompt): copy .env.example .env
  3. Open .env in a text editor and fill in values:
OLLAMA_API_KEY=...          # https://ollama.com/settings/keys
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=you@gmail.com
SMTP_PASSWORD=your-app-password
EMAIL_FROM=you@gmail.com
EMAIL_FROM_NAME=Your Name
MIN_SCORE=70

Gmail: use an App Password, not your normal login password.

6. Install Python libraries and run

You need Python 3 installed. Then in the extracted apply-workflow folder:

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python apply_jobs.py
  • Each lead is keyed by post_url (fallback: emails + description) inside apply-results.json.
  • Re-running the script skips anything already processed — no duplicate emails.
  • Low-score posts are still saved with their score.
  • On Ollama failure the script prints the error and exits; prior progress stays saved.
  • Email send failure also stops the run, and that lead is not marked processed so you can retry.

Before you run for real

  • Only leads with an email address can be emailed; others are skipped and logged.
  • Start with a small CSV (a few rows) to verify scoring and SMTP.
  • You are responsible for how you contact people — use this carefully.
