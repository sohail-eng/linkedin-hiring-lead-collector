🎯

Purpose

View and analyze hiring leads collected from LinkedIn using the Hiring Lead Collector Chrome extension. Upload your exported data to filter, search, and explore job opportunities.

📥

How to Use

  1. Install the Chrome extension (download below)
  2. Go to LinkedIn feed or search results (#hiring, #jobs)
  3. Open extension → Set location/keyword filters (optional)
  4. Click Start → Scroll through posts
  5. Click Stop & Export or Export All
  6. Upload the .csv or .json file here
✨

Features

  • Smart Filters: By email, apply link, company
  • Live Search: Across all fields instantly
  • Sort & Paginate: By date, author (25/page)
  • Detail Panel: Click row for full lead info
  • Description Modal: Click description to expand
  • Responsive: Works on mobile & desktop
📊

Data Fields

  • Post date & original label
  • Author name & company
  • Full post description
  • Extracted emails
  • Application links (lnkd.in, job URLs)
  • Post URL (open on LinkedIn)
  • Relevance & status tracking
